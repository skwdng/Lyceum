# 思弈阁 · 五个 UI 方向（供选择）

> 现状：暖米色纸感 + 蓝色主色 + 左侧栏，信息密度偏工具化。
> 下面五套是**同一个对局页骨架**在不同视觉语言下的样子，用来挑「气质」，不是最终像素稿。
> 可直接打开看：[UI方向-五套.html](mockups/UI方向-五套.html)（页签切换 A–E，或加 #B 直达）。
> 截图：docs/mockups/shots/ui-A.png … ui-E.png（1440×960）。

## A · 庭辩现场（Chamber）

**隐喻**：把对局做成一场「开庭」——胡桃木桌、黄铜席位牌、宣纸发言稿。

| 项 | 内容 |
|---|---|
| 主色 | 胡桃木 `#1B1714` / 黄铜 `#C9A227` / 勃艮第 `#8C2F39` / 米白 `#ECE2D4` |
| 字体 | 衬线（思源宋体 / Songti），标题字重 700，正文 14/1.9 |
| 布局 | 左栏变成竖排席位牌；发言像稿纸（细横线）；评分卡做成「判词」 |
| 标志组件 | 黄铜席位牌（选中时压印发光）、蜡封式「结束发言」按钮、判词卡 |
| 动效 | 墨水晕开 240ms，翻页 160ms；不用弹跳 |
| 适合 | 想强调「正式、有仪式感、像比赛」；适合面向辩论社/赛事 |
| 成本 | 中（字体 + 纹理 + 组件重绘），约 3–4 人日 |
| 风险 | 深色木纹容易显脏；长文本阅读疲劳需控制对比度 |

## B · 思辨仪器（Instrument）

**隐喻**：把辩论当成信号处理——步进刻度、波形、雷达、token 预算都是仪表。

| 项 | 内容 |
|---|---|
| 主色 | 石墨 `#0B0F12` / 荧光绿 `#B6FF3B` / 青 `#22D3EE` / 冷白 `#DBE9EE` |
| 字体 | 等宽（JetBrains Mono / Cascadia），数字等宽对齐 |
| 布局 | 12 栅格；左窄图标栏；中部时间线；右侧遥测面板（节奏/预算/辅助） |
| 标志组件 | 步进刻度尺（当前步高亮 + 总步数）、波形气泡、仪表盘式雷达 |
| 动效 | 扫描线 1.2s 循环、数字滚动 400ms；尊重 `prefers-reduced-motion` |
| 适合 | 想突出「AI + 训练工具」的专业感，面向重度用户与答辩演示 |
| 成本 | 中高（需要一套图表/刻度组件），约 4–5 人日 |
| 风险 | 荧光绿大面积使用刺眼；等宽中文可读性一般，正文要换回黑体 |

## C · 纸上推演（Paper）

**隐喻**：像辩手在桌上摊开的稿纸、便签、批注箭头——「思考过程本身是产品」。

| 项 | 内容 |
|---|---|
| 主色 | 米纸 `#F4EEE2` / 墨黑 `#221D17` / 印章红 `#B93B2E` / 铅笔灰 `#7A6F60` |
| 字体 | 标题楷体（Kaiti），正文宋体，批注手写感 |
| 布局 | 便签式气泡（轻微旋转 ±0.2°）、论据卡像钉在板上的卡片、批注用箭头连到原句 |
| 标志组件 | 红章「驳」「证」「问」、便签卡、手绘箭头、批注贴 |
| 动效 | 纸片滑入 180ms、盖章 120ms 缩放；不用模糊 |
| 适合 | 想做成「学习/笔记」气质，和社区、教程内容天然贴合 |
| 成本 | 低中（现有浅色底最接近），约 2–3 人日 |
| 风险 | 旋转/阴影多了会显乱；移动端要关掉倾斜保持整齐 |

## D · 深夜电台（Radio）

**隐喻**：一场深夜直播——「ON AIR」、频谱、玻璃面板、主播与嘉宾对谈。

| 项 | 内容 |
|---|---|
| 主色 | 午夜蓝 `#0D0F1E` / 琥珀 `#FFB347` / 紫 `#7C5CFF` / 冷白 `#EEF0FB` |
| 字体 | 无衬线（Inter / 思源黑体），数字等宽 |
| 布局 | 浮动玻璃卡；底部「传输条」（播放/暂停式控制）；席位做成频率刻度 |
| 标志组件 | ON AIR 呼吸灯、实时波形、玻璃气泡、底部传输条 |
| 动效 | 呼吸光 2.4s、波形 60fps；低性能设备降级为静态条 |
| 适合 | 想强调「陪伴感、语音输入、实时对谈」，也最适合做短视频/直播导流 |
| 成本 | 中（玻璃拟态 + 波形），约 3–4 人日 |
| 风险 | 玻璃+模糊在低端机耗电；深色下长文阅读要控制行高 |

## E · 竞技场（Arena）

**隐喻**：体育转播——比分牌、队色、下三分之一字幕条、倒计时环。

| 项 | 内容 |
|---|---|
| 主色 | 黑 `#080808` / 红 `#FF3B30`（正方）/ 蓝 `#2F6BFF`（反方）/ 白 `#F4F4F5` |
| 字体 | 窄体大标题（Bebas / Arial Narrow 替代）+ 黑体正文 |
| 布局 | 顶部大比分牌；发言按阵营左右分屏；底部字幕条显示当前环节与剩余时间 |
| 标志组件 | 比分牌、队色条、倒计时环、回合角标（ROUND 3/19） |
| 动效 | 硬切 120ms、数字翻牌 200ms |
| 适合 | 想强调「对抗感、输赢、可直播」，适合赛事/排行榜运营 |
| 成本 | 中（组件不多，但排版规则严格），约 3 人日 |
| 风险 | 强对抗气质可能和「训练」定位冲突；红蓝高饱和需谨慎用于长文 |

## 怎么选：三个问题

1. **这是训练工具还是赛事产品？** 训练 → A/C/D；赛事 → E；工具+演示 → B。
2. **用户最长停留的页面是哪个？** 对局页读长文，深色要慎用；复盘页适合深色（A/B）。
3. **要不要和社区/短视频共用一套语言？** 要 → C（纸感）或 D（电台）更容易统一。

## 我的建议（若只选一套）

- **主推 B + C 的混合**：对局页用 B 的「仪器感」表达节奏与评分（刻度、预算、辅助），复盘与社区用 C 的「纸感」承载长文与笔记；两者共用一个中性底，切换不突兀。
- 若面向答辩/演示，**A 最有记忆点**（一进门就知道这是「辩论」而不是聊天工具），但开发成本最高。
- 若这一版只想低风险换皮，**C 是唯一能在现有浅色底上平滑迁移的**。

## 落地方式（任一方向）

1. 先只改 `tokens.css` 的色/字/圆角，不动布局 —— 一天内能看到 70% 的效果；
2. 再改三个标志组件（席位条、气泡、辅助库）；
3. 最后动布局（侧栏/比分牌/刻度），并补 375px 与 `prefers-reduced-motion`。

> 注：五套稿都是纯 HTML/CSS，可直接在浏览器里改数值试；确认方向后我按选定的一套重做 `web/src/style.css` 与 `tokens.css`，并把对局页/复盘页先迁过去。
