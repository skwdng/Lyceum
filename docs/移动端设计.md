# 移动端 Web 设计说明（2026-11-28）

> 目标：390×844 下先能用、再好看；桌面（≥861px）完全不受影响。
> 截图：`docs/mockups/shots/mobile-{solo,match,hot,wallet,settings,community,video,me,matches}.png`

## 1. 壳层（≤860px）

- **顶部应用栏** 52px：返回 / 品牌 · 页面标题（单行省略）· 头像；滚动贴顶、毛玻璃。
- **底部 tabbar** 5 项：辩论 / 联机 / 社区 / 视频 / 我的
  - `flex:1; min-width:0`，SVG 线性图标 20px + 10.5px 文字，选中项主色药丸底；
  - `padding-bottom: env(safe-area-inset-bottom)`；
  - **对局页整条隐藏**（沉浸式，输入框贴底）。
- **页面节奏**：页距 16px，卡片圆角 16 / 轻阴影，按钮与输入 ≥44px。
- **标题去重**：顶栏已显示页面名时，页面里同名的 `h1.pg` 自动打 `dup-title` 并隐藏（按文案比对，不按路由硬编码）。

## 2. 对局页

- 头部一行：题目 17px 两行截断 + 「第 N 步 · 席位」+ ✕ 退出。
- 席位条：横向滚动 chips（`scroll-snap` + 两侧渐隐），当前席位主色描边。
- 聊天区吃满剩余高度，气泡最大宽 88%；B 方左起出字（ghost 占位）。
- 输入区 sticky 贴底：工具栏（语音 / 材料）+ 文本域 + 字数 + 发送 / 结束发言；
  「催一下 / 显示全文」只在「对方正在说话」那一行出现一次（不再重复）。
- 右侧栏收进底部抽屉：**进度 / 辅助 / 本场** 三个胶囊 → 半屏 bottom sheet，可下拉关闭。

## 3. 分页适配

| 页 | 移动端处理 |
|---|---|
| 热榜 | ≤640px 表格 → 卡片列表（名次徽章 + 标题 + 热度条 + 分数 + 紧凑「开辩」） |
| 钱包 | 两栏 → 单列；充值 2×2、按钮整行 44px；输入框 100% |
| 设置 | 皮肤卡单列、44px；只列现有三套皮肤 |
| 社区 / 视频 / 我的 / 对局列表 / 能力分析 | 沿用 16px 页距与卡片规则，实测无横向溢出 |

## 4. 约束与验收

- 所有新样式颜色走 `var(--blue/--card/--line/--ink/--sub/--blue-w/--red)`，切三套皮肤时壳层同步变色。
- 验收：390×844 逐页 `scrollWidth == 390`、tabbar 宽 390（对局页不显示）、最小可点高 ≥44px；
  桌面回归 `verify_prod_full` 21/21。
