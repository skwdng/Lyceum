## 1. 通用约定

| 项 | 约定 |
|---|---|
| 前缀 | `/api/community/**`（不得与 `/api/matches`、`/api/topics` 混） |
| 身份 | **JWT**：请求头 `Authorization: Bearer <token>`（2026-11-03 起）。`sub` 即 `userId`，由 `JwtAuthFilter` 校验后放进 `UserContext`。**不再接受** `X-User-Id` / 请求体 `userId` / `userName`——那套可伪造，已废弃。登录契约见 `docs/认证接口契约.md` |
| 昵称 | 一律取 `sy_user.name`（`left join sy_user u on u.id = p.author_id`）。发帖**不再**用请求体昵称覆盖；改名后在「我的」里改，列表/详情/评论立刻生效 |
| 响应包 | 列表类：`{items:[], total, page, size}`；**无** `pages` / `hasMore` / `totalCount`，前端自己算 |
| 分页 | `page` **从 1 起**；`size` 夹在 **1..50**；默认：列表 20 / 评论楼 10 / 楼中楼 20。前端须读回响应里的 `size`，不要用自己传的值 |
| 时间 | 一律 **epoch 毫秒数字**（如 `1762000000000`），**不是** ISO 串、不是 `yyyy-MM-dd HH:mm` |
| 命名 | 后端输出 **camelCase**；前端**禁止**再读 snake_case（原先的双兼容在 T8 收口） |
| 空数组 | 返回 `[]`，不返回 `null`；`lastCommentAt` / `updatedAt` 可为 `null` |
| 写接口返回 | `{postId}` / `{commentId}`；点赞与浏览返回 **204 无 body** |
| 错误体 | `{"code":"POST_NOT_FOUND","message":"..."}`；`code` 机读、`message` 可读。前端**按 code 分支，不按 HTTP 状态猜** |
| 层级 | 评论最多**两层**：楼（`root_id IS NULL`）+ 楼中楼（`root_id = 楼id`）。**客户端不得提交 `rootId`**，服务端派生（R-COM-19） |
| 软删除 | `status=1` 正常 / `status=2` 已删；列表、详情、评论三处都过滤 `status=1` |
| 摘要 | 服务端**写入时**生成，剥 Markdown 后按码点截 199 字 + 省略号（≤200）；**列表 SQL 不 select body**（R-COM-05） |
| 敏感词 | 命中**照样发布**，正文逐码点替换为全角＊（U+FF0A）后落库，摘要基于替换后正文；**禁止返回 `CONTENT_BLOCKED`**（R-COM-39 / D5） |

### 1.1 权限矩阵（未登录可读，写操作必须登录）

| 接口 | 未登录 | 已登录 |
|---|---|---|
| GET 列表 / 详情 / 评论 / 楼中楼 | 200，`liked` 恒 `false` | 200 |
| POST `/posts/{id}/view` | **204，但不计数** | 204，计数（自然日去重） |
| POST/PATCH/DELETE 其余全部 | **401 `UNAUTHORIZED`** | 200 / 204 |

> **社区禁言（2026-11-03）**：被禁言的用户 **发帖 / 评论 / 编辑帖子 / 点赞** 返回 `403 MUTED`（message 带到期时间）；
> **删除自己的帖或评论、取消点赞、浏览** 一律正常——删除是净化行为，不能被禁言卡住。
> 禁言只查 `sy_community_ban`，与「全站封禁」（`sy_user.status`，连登录一起拦）互不干扰。

> 实现：`JwtAuthFilter` 只注册在 `/api/community/*`，匿名写请求在过滤器就被挡掉；
> Controller 里再用 `UserContext.require()` 兜一层。`/api/auth/*` 不经过该过滤器。

## 2. 三个 DTO 字段表（前端只准读这些）

**post item**（列表与详情共用；详情多两个字段）
```
id(long) type(CHAT|GUIDE|HELP) title excerpt topicId topicTitle
authorId authorName commentCount likeCount viewCount liked(bool)
lastCommentAt(ms|null) createdAt(ms)
详情追加： body(Markdown) updatedAt(ms|null)
```

**楼（root comment）**
```
id postId authorId authorName body likeCount liked createdAt
replies[]   ← 前 3 条楼中楼
replyCount  ← 该楼楼中楼总数
```

**楼中楼（reply）**
```
id postId rootId authorId authorName body likeCount liked
replyObjectType(POST|COMMENT) replyObjectCommentId replyObjectUserName createdAt
```

> 计数三个口径，别混：
> - `post.commentCount` = 楼 + 楼中楼（R-COM-22）
> - 评论列表 `total` = **仅楼数**
> - 每楼 `replyCount` = 该楼楼中楼数
> 出参**禁止**出现段位 / 等级 / 积分 / 场次 / 贡献值（R-COM-03、§11#13）。

### 3.1 治理接口（2026-11-03 新增，3 个）

| # | 方法 路径 | 入参 | 成功 | 失败 |
|---|---|---|---|---|
| 15 | POST `/reports` | `{targetType:POST\|COMMENT, targetId, reason:SPAM\|ABUSE\|ILLEGAL\|OTHER, detail?}` | `{reportId}` | 400 参数不合法 / 不能举报自己；404 目标不存在或已删；**409 `ALREADY_REPORTED`**；401 |
| 16 | GET `/my-reports` | `page? size?` | `{items,total,page,size}` | 401 |
| 17 | GET `/me/ban` | – | `{banned, until, reason}` | 401 |

- `detail`（补充说明）≤500 字，**落库前过 `SensitiveWordMasker` 打码**（治理决策 D8）。
- 同人同目标只能举报一次，唯一索引 `ux_report_once` 兜底。
- 「我的举报」item：`{reportId,targetType,targetId,targetSummary,reason,detail,status,action,createdAt,handledAt}`，
  `status` = `PENDING|ACCEPTED|REJECTED`，`action` = `IGNORE|DELETE|BAN|DELETE_AND_BAN`（处理前为 null）。
- `me/ban` 的 `until` 是 **epoch 毫秒**，与全站时间格式一致。
- 管理侧接口见 `docs/管理接口契约.md`（不在本契约范围内）。

派生规则（R-COM-17/18/19）：
- `replyObjectType=POST`（默认）→ 楼：`root_id=NULL`，`replyObjectCommentId`/`replyObjectUserId` 均 NULL
- `replyObjectType=COMMENT` → 楼中楼：`root_id` = 被回复评论**所属那一楼**的 id（回复楼中楼时仍是原楼 id）
- 删楼 → **连带软删**其下所有楼中楼；删楼中楼只删自己。删评论只能作者本人。

## 4. 错误码映射（前端按 `code` 分支）

| code | HTTP | 触发 | 前端文案 |
|---|---|---|---|
| `INVALID_PARAM` | 400 | type 非法 / 正文超长 / 空标题 | "参数不合法：{message}" |
| `POST_NOT_FOUND` | 404 | 帖子不存在**或已删除** | "帖子已删除或不存在" |
| `COMMENT_NOT_FOUND` | 404 | 评论不存在 / 传了楼中楼 id 去查 replies | "评论已删除" |
| `NOT_AUTHOR` | 403 | 非作者改/删 | "只能操作自己的内容" |
| `UNAUTHORIZED` | 401 | 未登录做写操作 / token 无效 / 已过期 / 已登出 | "请先登录" |
| `ALREADY_REPORTED` | 409 | 同一人重复举报同一目标 | "你已经举报过这条内容" |
| `MUTED` | 403 | 社区禁言中（发帖 / 评论 / 编辑 / 点赞），`message` 带到期时间 | 直接展示 message |
| `ACCOUNT_DISABLED` | 401 | 账号被全站封禁 | "账号已被封禁" |
| `NOT_ADMIN` | 401 | 管理员令牌被拿来调社区接口 | "请用普通账号登录" |
| `SERVICE_UNAVAILABLE` | 503 | Redis 不可用（token 黑名单查不了） | "服务暂时不可用，请稍后再试" |
| `INTERNAL_ERROR` | 500 | 兜底 | "服务异常，请重试" |
| ~~`CONTENT_BLOCKED`~~ | – | **已废弃**（§18 R-COM-39 禁止） | 删除该分支 |

业务限制（服务端校验，前端不做前置校验）：标题必填 ≤120 字；正文必填 ≤200000 字；评论正文必填 ≤1000 字。

## 5. 参数容错矩阵（写死，不许"顺手统一"）

| 参数 | 非法时 | 说明 |
|---|---|---|
| `type` | **400 报错** | 白名单 `CHAT`/`GUIDE`/`HELP` |
| `sort` | 静默降级 `NEW` | `NEW`/`COMMENTS`/`LIKES`/`HOT`，大小写不敏感 |
| `range` | 静默降级 `ALL` | `ALL`/`3D`/`7D`/`OLDER`（OLDER = 早于 7 天） |
| `page` | 夹到 1 | |
| `size` | 夹到 1..50 | 传 100 会被静默改成 50 |

> 同为"非法枚举"，`type` 报错而 `sort`/`range` 静默——这是既有契约。**不许统一。**
> `title` 只搜标题（`title LIKE '%kw%'`），不搜正文，不用全文索引/ngram（R-COM-10）。

## 8. 本机环境事实（2026-11-02 实测）

| 项 | 值 |

| Redis | Docker 容器 `wdacg-redis`（redis:7-alpine），`127.0.0.1:6379`，`requirepass wdacg123456`，`--appendonly yes`。**本地测试复用该实例**（用户 2026-11-02 确认） |
| MySQL | Docker 容器 `wdacg-mysql`（mysql:8.0），`127.0.0.1:3307`，`root` / `wdacg123456`，库 `siyige` |
