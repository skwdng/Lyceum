# 归属边界与「不改对方代码」的做法

> 依据 `docs/协作规范.md` 划的模块归属。本文只解决一个问题：
> **我这边要修的问题落在他的模块里，怎么办？**

## 一、边界（谁改谁）

| 目录 / 文件 | 归属 |
|---|---|
| `com/siyige/community` `social` `notify` `admin` `analytics` | 他 |
| `web/src/views/{CommunityView,PostDetailView,ChatView,FriendsView,NotifyView,LoginView,MeView}.vue`、`views/admin/**` | 他 |
| `web/src/components/AppShell.vue`、`stores/{auth,chat,unread}.js` | 他 |
| `schema-{community,social,notify,analytics,admin,auth,security}.sql`、`community-sensitive-words.txt` | 他 |
| `com/siyige/{engine,service,ai,hot,domain,judges,billing,video,bootstrap}` | 我 |
| `web/src/views/{SoloView,MatchView,ReviewView,RoomView,DiagView,RecordsView,HotView,VideoView,OfflineView}.vue` | 我 |
| `web/src/stores/debate.js`、`miniprogram/**` | 我 |
| `api.js` `router.js` `nav.js` `style.css` `application.yml` `schema.sql` | **共享**（改要说明） |

## 二、三种不改他代码的替代做法

### 做法 1：改服务器配置，不改代码

**案例：`/admin` 跳转指向内网地址**

他的 `AdminPageController` 用 `redirect:v2/index.html#/admin`，被容器按 Host 头改写成
`http://127.0.0.1:8090/...`，外部打不开。**不用改他的 Java**，nginx 加一条即可：

```nginx
location = /siyige/admin {
    return 302 /siyige/v2/index.html#/admin;
}
```

优先级高于反代，请求根本到不了他的控制器；本地开发 `/admin` 本来就正常（localhost 就是对的）。

### 做法 2：放到自己的包里，用启动钩子做

**案例：管理员账号初始化**

管理端是独立账号体系、没有注册接口，需要一个「库里没有管理员就建一个」的启动逻辑。
放他的包（`com.siyige.admin`）也能跑，但那是我在往他的目录里加东西。

→ 放到 **`com.siyige.bootstrap.AdminSeeder`**（我的包）。效果一样，边界干净：
他的包一行没动，我这边多一个启动组件。

### 做法 3：提 patch + 说清楚，让他自己改

**案例：`schema-admin.sql` 的种子管理员**

```sql
-- 他的写法：每次启动都覆盖密码
merge into sy_admin(account, password_hash, status) key(account)
values ('admin', '<hash>', 1);
```

后果：管理员改过的密码，下一次部署/重启就被打回 `admin123`（线上实测踩到）。

**这处没法绕**——种子语句在它的 schema 文件里，只能改它。处理方式：

1. 改最小一处（`merge` → `insert … where not exists`），**不带任何其它改动**
2. 在提交信息里写明原因和线上现象
3. 同时把补丁内容和理由写进这里，方便他复核

## 三、工具：归属守卫

```bash
node scripts/ownership-guard.mjs                 # 看工作区
node scripts/ownership-guard.mjs --staged        # pre-commit 用
node scripts/ownership-guard.mjs --range A..B    # 看某个提交区间
```

输出三档：

```
⛔ 动了队友的模块（退出码 1）
⚠ 共享基建（改完要说明）
✓ 你自己的模块
```

装上 pre-commit 钩子（可选，不装也能手动跑）：

```bash
printf '#!/bin/sh\nnode scripts/ownership-guard.mjs --staged || exit 1\n' > .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

## 四、当前还是越界的 4 处（待他复核）

| 文件 | 改了什么 | 为什么绕不开 |
|---|---|---|
| `schema-admin.sql` | 种子 `merge` → `insert … not exists` | 种子语句只能在这里改 |
| `components/AppShell.vue` | **只加**移动端底部 tab + 一段 media query | 外壳是他的组件，手机导航必须挂在这里 |
| `views/LoginView.vue` | **只加**失败时就地提示（`authError`） | 登录页是他的 |
| `views/MeView.vue` | **只加**退出登录前的 confirm | 同上 |

四处都是**纯新增行，没有删他的逻辑**。他要是不同意，把补丁摘掉即可——不会牵连别的功能。
