## 1. 项目是什么

**思弈阁 · Lyceum**：AI 4v4 辩论训练系统 + 社区生态平台。
核心是训练闭环：8 个 AI 辩手各占一席、各有打法，用户坐其中一个位置打完整场，结束后拿到五维评分、逐回合点评、改写建议与能力雷达。

- 线上：<http://120.24.204.138:8787/siyige/>
- 本地：`http://localhost:8080`（H2 内存库，重启即丢数据）
- 定位口径（答辩/README 必须一致）：**以辩论训练为核心、带社区生态的平台**；新增功能先问「它让训练更有效吗」，答不上就不做。

## 4. 赛制与节奏（改之前先看这里）

```
18 步 = 4 立论（A1 立论 / B1 立论 / A2 驳立论 / B2 驳立论）
      + 8 质询（每方 2 轮：A 问→B 答→B 问→A 答）
      + f 自由辩（3–6 轮，席位轮转 A2→B2→A3→B3）
      + 2 总结（B4 → A4）
SPRINT 模式跳过质询 = 10 步
QUERY_MIN/MAX = 2/2；FREE_MIN/MAX = 3/6
步数字数上限：立论 260 / 驳立论 200 / 质询问 100 / 质询答 120 / 自由辩 140 / 总结 280
AI 接话间隔：aiGapMs=3500 + jitter 2500（快攻派 ×0.85、价值/归谬派 ×1.25），开场 2200ms
单人模式：不限时、不抢拍；多人：自由辩 8–12 秒抢拍窗口
打字机：per = clamp(6500/字数, 18, 150) ms，标点处停顿
```

关键表：`sy_match`（一局一行：step / deadline_at / last_active_at / my_seats / phase / buzz_seat）、`sy_turn`（一回合一行，content ≤4000，status=`OK|EMPTY|TIMEOUT`）。

## 5. 跑起来 / 验证 / 部署

```bash
# 后端单测（840 项，1 项 skip=等待人工标注）
mvn -f server/pom.xml test

# 前端构建（产物进 server/src/main/resources/static/v2/）
cd web && npm run build

# 本地起服务
mvn -f server/pom.xml package -DskipTests && java -jar server/target/siyige-backend-0.1.0.jar

# 部署（把 jar 换上去 + 重启 + 自检）
scp server/target/siyige-backend-0.1.0.jar root@120.24.204.138:/opt/siyige/siyige.jar
ssh root@120.24.204.138 'systemctl restart siyige && sleep 26 && bash /opt/siyige/predeploy_check.sh'

# 线上自检（本地跑，需 Chrome/Edge + CDP）
node scripts/verify_prod_full.mjs <调试端口> http://120.24.204.138:8787/siyige
node scripts/smoke_routes.mjs    <调试端口> http://120.24.204.138:8787/siyige
```

`predeploy_check.sh` 会查 5 层：服务状态 → 8090 自身 → **8787 公网入口** → 静态页/题库接口 → 代理代码块是否还在。**只查 8090 会漏掉代理层故障**（曾因此全站 404）。

## 6. 已经踩过的坑（别再踩）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| `parseSeats("")` 默认 `{A1}` | 房间对局把提交者当成 A1，替人发言 | 反查提交者席位用 `parseSeatsStrict` |
| `num()` 不认 Timestamp | 僵尸回收 anchor 恒为 0，**从来没生效** | 用 `numLong()`，并用 `last_active_at` 判活跃 |
| 单人模式 deadline 为 NULL | 打满 15 分钟被误判 ABANDONED | 回收按 `last_active_at`，不按 `started_at` |
| `advance()` 抛异常后 tick 重试 | 同一步插入多条 → 前端 key 撞车 → 气泡文字叠 N 遍 | 插入前 `store.hasTurn()` 查重 + 同一步生成上限 3 次 |
| 模型退化循环 | 同一段话换说法重复 5–10 遍 | `AiService.cutRepeats()`（同句第二次出现即截断） |
| 打字机只在 mount 时启动 | 首条发言整段弹出 | `load()` 兜底 + watch turns 长度 |
| 输入框只在“轮到我”时渲染 | 对方说话时粘贴无处可去 → “粘贴发不出去” | 输入框常驻 + `onPaste` 清洗（零宽/多空行/1800 字上限） |
| lifekit 更新丢路由 | `/siyige/*` 全 404，全站打不开 | `python3 /opt/siyige/fix_route.py && systemctl restart lifekit` |
