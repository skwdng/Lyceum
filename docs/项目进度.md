- [x] 未读语义回归固化进自检 U1~U4（在别页收消息红点要亮且不误标 / 回来自动打开并清零 /
  刷新后列表态不误标、点开才清 / 看 A 会话时 B 会话的消息仍算未读）
- [x] 修复（2026-11-07 用户实测反馈）：**换账号串状态**。退出后用同一个标签页登录另一个账号，
  点「消息」会出现「标题是自己、看的是上一个账号的会话、未读消不掉、发消息报失败」。
  根因：登录/注册/退出都没有清 `S.chat` / `S.social` / WebSocket 补拉位置，旧账号的 convId 与 peer 被沿用。
  已加 `socialReset()`（登录/注册/退出都调），并让 `chatOpen` 先丢弃旧 peer 与旧消息、
  加载失败就地显示可重试错误（不再拿旧数据分析），`loadChat` 发现当前会话不在列表里就作废。
  顺带修掉「点没有未读的会话看不到历史、发一条才出现」——同一个根因（convId 指向了旧账号的会话）

| 层 | 选型 |

```
web/                            Vue 3 源码
├── src/views/                  一人一块（原 js/views/* 一一对应）
├── src/router.js  nav.js       Hash 路由与侧栏（共享，只追加）

server/src/main/resources/static/

```
