## 验收清单（你自己核对）

```bash
# 1. 编译
mvn -q clean package -DskipTests

# 2. 起中间件
docker compose up -d

# 3. 起应用
export DEEPSEEK_API_KEY=sk-xxx
java -jar target/siyige-0.0.1-SNAPSHOT.jar

# 4. 三项连通性
curl http://localhost:8080/api/health
curl http://localhost:8080/actuator/health     # 应为 {"status":"UP"}
curl -s http://localhost:8080/actuator/env | findstr virtual   # 确认虚拟线程已开
```

| 检查项 | 通过标准 |
|---|---|
| 编译 | 无 ERROR，`target/*.jar` 生成 |
| 启动 | 无 `BeanCreationException`，日志出现 `Tomcat started on port 8080` |
| MySQL | `SHOW TABLES` 能看到 `t_user`、`t_topic`，`t_topic` 有 12 行 |
| Redis | `redis-cli -a 密码 ping` 返回 PONG |
| 虚拟线程 | 启动日志或 `/actuator/env` 中 `spring.threads.virtual.enabled=true` |

## 常见被 AI 写错的地方（提前检查）

1. **漏 `spring-boot-starter-webflux`** → 后面 `.stream()` 抛 `NoClassDefFoundError: reactor/core/publisher/Flux`
2. **两个 `ChatClient` Bean 用同一个 `ChatClient.Builder` 注入** → 报 `NoUniqueBeanDefinitionException`，应各自 `builder.mutate()` 或分别 build
3. **`init.sql` 里辩题标题和原型不一致** → 后面联调时前端列表对不上，返工
4. **MyBatis-Plus 版本用了非 boot3 的 starter** → 启动报 `Invalid value type for attribute 'factoryBeanObjectType'`
5. **application.yml 里写了 `spring.ai.deepseek.*`** → 错误，1.1.8 的 DeepSeek 走 `spring.ai.openai.*` 前缀 + 自定义 base-url（AI 常写错，让它改用官方 starter 的配置前缀前先验证启动日志）
